# Security Policy

## Scope

This repository is a public, sanitized showcase for Nexus AI. It intentionally excludes production source code, credentials, customer data, private infrastructure details, and proprietary implementation logic.

## Reporting a Security Concern

If you notice information in this showcase that could expose a credential, customer detail, private infrastructure reference, or other sensitive material, please report it privately to the repository owner rather than opening a public issue containing the sensitive information.

When reporting, include:

- A short description of the concern
- The affected file or section
- Why the information may be sensitive
- Any safe reproduction details that do not disclose secrets publicly

## Supported Content

Security review for this public repository focuses on accidental disclosure in documentation, screenshots, generated previews, workflow files, and other showcase assets.

The private production repositories and infrastructure are maintained separately and are not published here.

## Disclosure Principle

Please avoid posting secrets, access tokens, credentials, personal data, or exploitable private-system details in public issues, discussions, or pull requests.
